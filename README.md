# Lensetek CDN

Cdn aset statis untuk **cdn.lensetek.com**, di-hosting di GitHub Pages melalui akun [lensetek-int](https://github.com/lensetek-int).

- URL Pages: https://lensetek-int.github.io/lensetek-cdn/
- Kustom domain: https://cdn.lensetek.com (menggunakan CNAME di zone Cloudflare `lensetek.com`)
- CI: `.github/workflows/static.yml` (otomatis deploy pada push ke `main`)
